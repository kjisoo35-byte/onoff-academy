PLATFORM PHILOSOPHY

Platform 철학

기능이 아니라 업무 흐름을 연결합니다.

프로젝트는 단순한 작업 목록이 아니라 안전 승인을 받은 작업 단위입니다. 작업자는 프로젝트를 새로 만드는 대신 오늘 수행할 작업을 선택합니다. Safety Start는 작업 생성 기능이 아니라 준비된 작업을 시작하는 절차입니다.

INFO

Safety Report는 매일 작성하는 문서가 아니라 사고, Near Miss, 위험제보, 개선제안 또는 종사자의견이 발생했을 때 사용하는 Event Workflow입니다.

END-TO-END FLOW

Platform Workflow

승인된 작업이 안전하게 시작되고 기록되는 과정입니다.

  1. 01Project작업 정의 및 안전 승인
  2. 02Daily Work오늘 수행할 작업 선택
  3. 03Electronic Documents필요 문서 확인 및 서명
  4. 04Safety Start안전준비 확인 후 시작
  5. 05Work승인 범위 내 작업 수행
  6. 06Safety ReportEvent 발생 시 보고

각 단계는 이전 단계의 데이터를 다시 입력하는 대신 연결된 작업 정보를 이어받는 것을 원칙으로 합니다.

PROJECT GUIDE

Project

안전 승인을 받은 작업의 기준 정보입니다.

승인 Workflow

  1. 생성작업 범위와 기본 정보를 등록합니다.
  2. 안전문서 설정SOP, 위험성평가 및 추가 안전서류를 지정합니다.
  3. 안전관리 검토관리자가 작업 조건과 준비 문서를 확인합니다.
  4. ACTIVE승인 완료 후 오늘 작업에서 선택할 수 있습니다.
NOTE

ACTIVE 이전 프로젝트는 Daily Work의 작업 대상으로 사용하지 않습니다.

DAILY WORK GUIDE

Daily Work

작업자가 오늘 수행할 작업을 시작하는 흐름입니다.

  1. 오늘 작업 선택ACTIVE 작업에서 실제 수행 대상을 선택합니다.
  2. 필요 문서 확인작업 기준에 따라 전자문서가 자동 제시됩니다.
  3. 전자서명작업자가 문서 내용을 확인하고 서명합니다.
  4. Safety Start안전준비 사항을 최종 확인하고 작업을 시작합니다.
WARNING

필수 문서 확인이나 안전준비 절차가 완료되지 않은 경우 작업 시작 단계로 진행하지 않습니다.

WORK START

Safety Start

필수 안전준비를 확인한 뒤 오늘 작업을 시작합니다.

개요와 목적

Safety Start는 새로운 작업을 만드는 기능이 아닙니다. Daily Work에서 선택한 작업의 프로젝트 정보, 필수 전자문서와 안전준비 체크리스트를 최종 확인하는 시작 절차입니다.

  1. 작업 확인선택한 작업과 작업 위치를 확인합니다.
  2. 문서 확인필수 문서와 전자서명 완료 여부를 확인합니다.
  3. 안전준비 확인SOP, 위험성평가와 추가 항목을 확인합니다.
  4. 등록 및 검토제출 후 Manager의 기존 승인 Workflow를 따릅니다.
TIP

등록 전에 Project와 작업 위치가 오늘 수행할 업무와 일치하는지 확인합니다.

BEST PRACTICE

현장에서 확인한 사실을 기준으로 작성하고, 이전 작업의 내용을 그대로 반복 입력하지 않습니다.

EVENT WORKFLOW

Safety Report

작업 중 발생한 안전 Event를 기록하고 조치합니다.

사고

인적·물적 피해가 발생한 사건

Near Miss

피해 없이 종료되었지만 사고 가능성이 있었던 상황

위험제보

현장에서 발견한 위험 상태 또는 행동

개선제안

안전성과 업무 품질을 높이기 위한 제안

종사자의견

작업자가 전달하는 안전 관련 의견

NOTE

Safety Report는 정기 Daily Workflow가 아닙니다. Event가 발생한 시점에 등록하고 기존 검토·조치 Workflow에 따라 처리합니다.

Administration

  • 승인 대기 및 검토 중 작업 확인
  • Project 안전준비 체크리스트 검토

  • Safety Report 조치 상태 확인

  • Project 운영 기준 관리
  • 전체 Safety Workflow 모니터링
  • 전자문서 Template 및 완료 현황 확인

ADMINISTRATION

Settings

Platform 운영 기준과 환경 정보를 확인합니다.

운영 원칙

설정은 전체 Workflow에 영향을 줄 수 있으므로 변경 전 영향 범위를 확인합니다. Production 환경 설정은 승인된 배포 절차를 통해서만 변경합니다.

WARNING

권한, 데이터 저장소 또는 Worker 연결 설정을 변경할 때 Preview와 Production 환경을 명확히 구분합니다.

SUPPORT

FAQ

자주 확인하는 운영 기준입니다.

Project와 Daily Work의 차이는 무엇인가요?

Project는 승인된 작업 기준이고 Daily Work는 그중 오늘 수행할 작업을 선택하는 절차입니다.

전자문서를 직접 찾아야 하나요?

아니요. 선택한 작업의 기준에 따라 필요한 문서가 자동으로 제시되는 구조입니다.

Safety Report는 매일 작성하나요?

아니요. 사고, Near Miss, 위험제보, 개선제안 또는 종사자의견이 발생한 경우 작성합니다.
